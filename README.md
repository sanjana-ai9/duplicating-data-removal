# Day 23: Duplicate Data Removal Using Pandas

## 📌 Objective

To identify and remove duplicate records from a dataset using Python and Pandas.

## 🛠️ Tools Used

* Python
* Pandas
* Jupyter Notebook

## 📖 Description

In this task, I created a student dataset containing duplicate records. I used Pandas to identify duplicate rows, count them, and remove them from the dataset.

I also compared the number of rows before and after removing duplicates.

## 💻 Concepts Learned

* Creating a DataFrame
* Identifying duplicates using `duplicated()`
* Counting duplicate records
* Removing duplicates using `drop_duplicates()`
* Counting rows using `len()`

## 📊 Results

* Original number of rows: 6
* Number of duplicate records: 2
* Rows after removing duplicates: 4

## ✅ Conclusion

This task helped me understand how to identify and remove duplicate records using Pandas. Removing duplicates is an important step in data cleaning before performing data analysis.
